# Flutter CBT学習アプリ

## 作成の背景
AWS Certified Solutions Architect Associateの学習の際にローカルで問題を解きたい（外出先でも問題演習したい）となり、昨今話題となっている
バイブコーディングで作成してみようと思い作成した。

## 参考にした既存システム
CBT SolutionsのCBTシステム
オデッセイ CBTのCBTシステム
Peason VueのCBTシステム

## 使用した言語、フレームワーク
・Flutter SDK
・Dart
・JSON（データ管理）

## 動作環境
・Linux（開発時のメインPCがLinuxのため、今回はLinux用に調整しました）

## 機能
### A、問題登録
バリエーションは丸バツ、多肢択一、複数選択、記述に対応
配点や解説、メモが入れられる。

さらに、既存のCBTとは違って練習特化CBTアプリにするためにタグに対応。
タグによって問題絞り込みもできる！！

### B、演習
多肢選択などのバリエーションで絞り込み
タイムリミット機能でタイムアタックみたいなこともできる
選択肢ランダム表示により、解答の位置を覚えるということを防げる！

### C、模擬試験モード
本番さながらの模擬試験モードを実装
合格基準と制限時間を決めてスタート。終了時には所定のディレクトリにPDF成績表が各問題の解説付きで出力

### D、AI学習モード（現在分析機能のみ）
所定のルールに沿ってどの問題が苦手などという簡易レポートを出力
