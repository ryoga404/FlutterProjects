# 試験対策アプリ

Flutter 製のデスクトップ / モバイル対応試験対策アプリです。  
問題の作成・演習・成績分析・間隔反復学習を一元管理できます。

## 機能一覧

### 1. 問題セット管理

ホーム画面（`home_screen.dart`）でセットの一覧・操作を行います。

#### セット作成・編集
- **新規作成** — セット名・説明を入力して作成（右下 FAB）
- **セット情報を修正** — 名前・説明・試験日をまとめて編集
- **試験日カウントダウン** — 試験日までの残り日数をカードに表示  
  - 30日超：緑 / 8〜30日：オレンジ / 1〜7日：赤（警告） / 当日：フラグ表示
- **セットを複製** — 問題ごとコピーして別名で保存
- **削除** — セットと紐付く問題・解答履歴をまとめて削除

#### 並び替え
- ポップアップメニュー「セットを並び替え」から並び替えモードに入る
- ▲▼ ボタンでカードを上下移動し「保存」で確定

#### カードのバッジ表示
| バッジ | 内容 |
|---|---|
| 問題数 | セットに登録された問題の総数 |
| 回答数 | 累計解答回数 |
| 苦手N問 | 正答率 60% 未満の問題数（1回以上解答済み） |
| 今日の復習 N問 | 間隔反復スケジュールで本日復習が必要な問題数 |

#### セットへのアクセスボタン
各カードに「問題登録」「演習」「成績」「AI 学習」の 4 ボタンを配置。

### 2. 問題登録

`register_screen.dart` で問題を作成・編集します。

#### 問題タイプ（4種類）

| タイプ | 説明 |
|---|---|
| **丸バツ** | ○ / ✕ の二択 |
| **多肢択一** | 選択肢から 1 つを選ぶ |
| **複数選択** | 選択肢から複数を選ぶ（Set 比較で判定） |
| **記述** | 自由記述 → 模範解答と照合して自己採点 |

#### 入力項目
- **問題文**（必須）— 複数行入力対応
- **画像**（任意）— ギャラリーから添付・プレビュー・削除
- **選択肢**（択一・複数のみ）— 2〜8 個、追加 / 削除可能
- **正解設定** — ラジオボタン（択一）/ チェックボックス（複数）でタップ指定
- **配点**（任意）— 未入力時は 1 点
- **解説**（任意）— 回答後に表示
- **メモ**（任意）— 自分用ノート（復習ポイント・参考ページなど）
- **タグ**（任意）— Enter または「追加」ボタンで複数登録・削除可能

#### クリップボード貼り付けインポート ★

AppBar の貼り付けボタン（📋）または画面上部バナーから起動。  
コピーしたテキストを貼り付けるだけで問題文・選択肢・正解を自動パースします。

**自動パースのルール**

| 行の形式 | 判定結果 |
|---|---|
| 1行目（無条件） | 問題文 |
| `A.` `B.` `①` `②` `・` `-` `*` で始まる行 | 選択肢 |
| `正解:` `答え:` `正答:` `Answer:` で始まる行 | 正解 |

**サンプルテキスト（そのままコピー → 貼り付け → 自動パース対応）**

```
OSI参照モデルの第3層（ネットワーク層）のプロトコルはどれか。
A. TCP
B. IP
C. HTTP
D. Ethernet
正解: IP
```

```
データベースのACID特性に含まれないものはどれか。
1. 原子性（Atomicity）
2. 一貫性（Consistency）
3. 可用性（Availability）
4. 耐久性（Durability）
正解: 可用性（Availability）
```

```
IPアドレスからMACアドレスを解決するプロトコルの名称を答えよ。
答え: ARP（Address Resolution Protocol）
```

#### 問題管理（`question_list_screen.dart`）
- セット内の全問題を一覧表示（タイプ別バッジ・タグ表示）
- タイプ / タグでフィルタリング
- 問題の個別編集・複製・削除
- ドラッグ & ドロップで並び替え

### 3. 演習モード

`exercise_menu_screen.dart` → `exercise_screen.dart` で演習を行います。

#### 演習メニュー
| 項目 | 内容 |
|---|---|
| 問題タイプ絞り込み | 丸バツ / 多肢択一 / 複数選択 / 記述 のフィルタチップ |
| 苦手問題フォーカスモード | 正答率 N% 未満の問題だけを集中演習（閾値は 10〜90% でスライダー調整） |
| すべて順番に | 全問を登録順で出題 |
| ランダム | 全問をシャッフルして出題 |
| 問題数を指定してランダム | スライダーと数値入力で出題数を指定 |
| 模擬試験 | 問題数・合格基準・制限時間を設定して模擬試験へ |

#### 演習オプション（インライン設定）
| オプション | 内容 |
|---|---|
| タイムリミット | ON/OFF スイッチ + 秒数をテキストフィールドで直接編集 |
| 選択肢ランダム表示 | 毎回選択肢の順番をシャッフル |

#### 演習画面の機能
- **進行状況バー** — 上部に現在問題数 / 全問数を表示
- **タイマーバー** — 残り時間をプログレスバーと秒数で表示（50%超：緑 / 25%超：オレンジ / 以下：赤）
- **問題タイプバッジ** — 各問題にタイプを色分け表示
- **問題文の長押しコピー** — `SelectableText` でテキスト選択・コピー可能
- **回答 UI**（タイプ別）
  - 丸バツ：大型 ○ / ✕ ボタン（タップで即判定）
  - 多肢択一：ラジオボタン選択 → 「回答する」
  - 複数選択：チェックボックス複数選択 → 「回答する」
  - 記述：テキスト入力 → 「解答を確認する」 → 自己採点（正解 / 不正解ボタン）
- **正誤フラッシュオーバーレイ** — 正解 / 不正解をアニメーション表示
- **正誤詳細カード** — 選択した選択肢と正解を色分けで比較表示
- **解説表示** — 解答後に解説カードを展開
- **メモ欄** — 演習中にメモを記入・保存（常時表示）
- **この問題を修正ボタン**（AppBar 📝）— 演習を中断せずに登録画面へ遷移し、戻ると演習再開

#### 間隔反復スケジュール更新
演習で回答するたびに `updateReviewSchedule` を呼び出し、  
連続正解数に応じて次回復習日を自動更新します（→ [間隔反復スケジューラー](#7-間隔反復スケジューラー)）。

### 4. 模擬試験モード

`mock_exam_screen.dart` で本番に近い形式の試験を実施します。

#### 設定項目
| 項目 | デフォルト |
|---|---|
| 問題数 | 全問 |
| 合格基準（得点率） | 70% |
| 制限時間 | 60分（ON/OFF 切替可） |

#### 試験中の機能
- 問題はランダムシャッフルで出題
- 全問に番号ナビゲーションバー（未回答：グレー / 正解：緑 / 不正解：赤）
- 問題番号タップで任意の問題へジャンプ
- 制限時間カウントダウン（残り時間が少なくなると色変化）
- 「提出」ボタンで終了

#### 結果画面
- 合否判定（合格ライン到達 / 未達）
- 得点・得点率・正解数 / 問題数
- 問題別の正誤一覧（問題文・あなたの回答・正解を比較）
- 成績レポートの PDF 出力（試験直後から）

### 5. 成績・分析

`score_screen.dart` でセットの成績を 3 タブで確認します。

#### ① 解答履歴タブ
- 全解答履歴を一覧表示（問題タイプ・問題文・日時・正誤）
- **フィルタ**：全て / 正解のみ / 不正解のみ（サマリーカードをタップで切替）
- **日付絞り込み**：開始日・終了日を指定して期間フィルタ
- **並び替え**：解答日時の昇順 / 降順
- **ページネーション**：10件ずつ表示（‹ › ボタンで移動）
- **詳細ダイアログ**：履歴行タップで問題文・選択肢・正誤・解説・メモを表示

#### ② 推移タブ
- 正答率の推移をバーグラフで表示
- **表示単位**：日別（直近30日）/ 週別（直近12週）/ 月別（直近12ヶ月）
- バーの色：正答率 80%以上：緑 / 50〜80%：オレンジ / 50%未満：赤
- 直近データのサマリー（学習期間数・総回答・平均正答率）

#### ③ 問題別タブ
- 各問題の正答率を棒グラフ付き一覧表示（低い順にソート）
- 問題タップで詳細ボトムシート（問題文・選択肢・正解・解説・メモ・タグ・統計）

#### サマリーカード
画面上部に常時表示：

| 項目 | 内容 |
|---|---|
| 総回答 | 全解答回数 |
| 正解 | 正解数（タップで正解フィルタ） |
| 不正解 | 不正解数（タップで不正解フィルタ） |
| 正答率 | 通算正答率（%） |

#### CSV エクスポート ★
AppBar の 📊 ボタンから統計データを CSV で書き出します。  
**出力先**：`Documents/e-learning/exports/<セット名>_stats_<timestamp>.csv`  
**形式**：BOM 付き UTF-8（Excel で直接開ける）

出力セクション：
1. サマリー（セット名・総回答・正答率など）
2. 問題別統計（タイプ・タグ・正答率・連続正解数・次回復習日）
3. 日別統計（直近30日）
4. 解答履歴全件

#### PDF 出力
FAB「PDF出力」から成績レポートを PDF で書き出します。
- 抽出期間（開始日〜終了日）を指定可能
- 保存先ディレクトリを自由に指定

### 6. AI 学習分析

`model_training_screen.dart` / `ai_learning_service.dart` で学習データを分析します。

#### 分析内容（3タブ）

| タブ | 内容 |
|---|---|
| 概要 | 全体正答率・学習日数・総解答数・習得済み問題数 |
| 問題別 | 各問題の正答率・連続正解数・習得状況（習得済み / 苦手 / 学習中） |
| 予測 | 現在のペースでの習得完了予測日・推奨学習量 |

#### 習得判定基準
- **習得済み**：連続正解 3 回以上
- **苦手**：正答率 60% 未満（1回以上解答）
- **学習中**：上記以外

### 7. 間隔反復スケジューラー

エビングハウス忘却曲線に基づき、**連続正解数**に応じて次回復習日を自動計算します。

| 連続正解数 | 次回復習まで |
|---|---|
| 不正解（リセット） | 1日後 |
| 0回（初回正解） | 1日後 |
| 1回 | 3日後 |
| 2回 | 7日後 |
| 3回 | 14日後 |
| 4回 | 30日後 |
| 5回以上 | 60日後（習得済み扱い） |

- 演習・模擬試験どちらで回答しても更新される
- ホーム画面のカードに **「今日の復習 N問」** バッジとして表示
- 問題の `nextReviewAt` フィールドに保存（JSON 永続化）

### 8. インポート / エクスポート

#### JSON エクスポート / インポート（セット単位）
- セットの問題を JSON ファイルとして書き出し
- JSON ファイルを読み込んで別端末や別環境にインポート
- **出力先**：`Documents/e-learning/exports/<セット名>_<timestamp>.json`
- ID 衝突時は自動的に新しい ID を発行

#### CSV エクスポート / インポート（問題セット）
- 問題を CSV 形式で書き出し（Excel 対応）
- CSV テンプレート形式でインポート可能

**CSV フォーマット（ヘッダー行）**

```
type,question,choice1,choice2,choice3,choice4,choice5,choice6,choice7,choice8,answer,explanation,points,memo,tags
```

| カラム | 値の例 |
|---|---|
| type | `true_false` / `single_choice` / `multiple_choice` / `short_answer` |
| answer（複数選択） | 正解を `|` で区切る（例：`選択肢A|選択肢C`） |
| tags | タグを `|` で区切る（例：`重要|計算問題`） |

#### 統計 CSV エクスポート（成績画面）
→ [CSV エクスポート](#csv-エクスポート-)参照

### 9. バックアップ / リストア

設定画面（`settings_screen.dart` / `backup_service.dart`）でデータを保護します。

#### バックアップ作成
- 全データ（問題・問題セット・解答履歴・設定）を zip ファイルに圧縮
- **保存先**：`Documents/e-learning/backups/backup_YYYYMMDD_HHmm.zip`

#### バックアップ一覧
- 作成日時・ファイルサイズを一覧表示
- 各バックアップから「リストア」または「削除」が可能

#### リストア
- 選択したバックアップから全データを復元
- **注意**：現在のデータはすべて上書きされます（リストア後アプリ再起動推奨）

## データ構造

全データは `getApplicationDocumentsDirectory()/e-learning/` 以下に JSON で保存されます。

```
Documents/
└── e-learning/
    ├── questions.json       # 全問題データ
    ├── question_sets.json   # 問題セット一覧
    ├── answer_history.json  # 全解答履歴
    ├── settings.json        # アプリ設定
    ├── backups/             # バックアップ zip
    └── exports/             # JSON / CSV / PDF 出力ファイル
```

### Question（問題）

| フィールド | 型 | 説明 |
|---|---|---|
| id | String | ユニーク ID |
| setId | String | 所属セット ID |
| type | String | `true_false` / `single_choice` / `multiple_choice` / `short_answer` |
| question | String | 問題文 |
| choices | List\<String\>? | 選択肢（択一・複数のみ） |
| answer | dynamic | 正解（丸バツ: `"true"/"false"` / 択一: 文字列 / 複数: List / 記述: 文字列） |
| explanation | String? | 解説 |
| imagePath | String? | 添付画像のローカルパス |
| points | int | 配点（デフォルト 1） |
| memo | String? | 自分用メモ |
| tags | List\<String\> | タグ一覧 |
| nextReviewAt | DateTime? | 間隔反復：次回復習推奨日（null = 未解答） |

### QuestionSet（問題セット）

| フィールド | 型 | 説明 |
|---|---|---|
| id | String | ユニーク ID |
| name | String | セット名 |
| description | String | 説明 |
| createdAt | DateTime | 作成日時 |
| examDate | DateTime? | 試験日（任意） |
| sortOrder | int | 表示順 |

### AnswerHistory（解答履歴）

| フィールド | 型 | 説明 |
|---|---|---|
| id | String | ユニーク ID |
| setId | String | 問題セット ID |
| questionId | String | 問題 ID |
| questionText | String | 問題文スナップショット |
| correct | bool | 正誤 |
| userAnswer | dynamic | ユーザーの回答 |
| answeredAt | DateTime | 解答日時 |
